# EspoCRM Railway Template

Este template instala EspoCRM automaticamente no Railway.

## Variáveis necessárias

- DB_HOST = mysql.railway.internal
- DB_PORT = 3306
- DB_NAME = railway
- DB_USER = (gerado pelo Railway)
- DB_PASSWORD = (gerado pelo Railway)
- ADMIN_EMAIL = admin@admin.com
- ADMIN_PASSWORD = sua_senha
- SITE_URL = URL pública do Railway

## Deploy

1. Crie um repositório no GitHub
2. Copie todos os arquivos deste template
3. No Railway → New Service → Deploy from GitHub
4. Configure as variáveis
5. Deploy
